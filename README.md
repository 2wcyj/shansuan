# 膳算

这是运行在当前Windows电脑的个人营养与生活管理应用“膳算”。无需登录，日常不使用外网、云数据库或云端AI。

1. 首次双击 **安装桌面应用.cmd**，桌面会创建“膳算”图标，以后双击图标即可在独立应用窗口中打开。
2. 首页及各模块继续使用当前电脑上的原有加密资料；只有确认吃过的食物才计入摄入。
3. 关闭窗口不删除数据；要停止本机后台服务，双击 **停止.cmd**。

正式个人资料保存在 `%LOCALAPPDATA%\MyNutritionAssistant` 的独立加密文件中，刷新或清除浏览器数据不会删除它们。请在“个人档案”中创建带密码的便携备份，另存到其他磁盘。

使用方法、备份恢复、模型等待与故障处理见 [使用说明](docs/user-guide.md)。桌面入口与数据保护见 [膳算桌面版](docs/desktop-app.md)。安装维护见 [安装说明](docs/installation.md)，开发与测试进度见 [实施进度](docs/progress.md)，逐项验收见 [验收记录](docs/acceptance-results.md)。

完整测试入口为 **测试.cmd**。测试使用独立目录和合成档案，包含真实本地模型与Edge操作。
