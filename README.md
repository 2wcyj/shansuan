# 我的生活营养助手

这是在当前Windows电脑浏览器运行的个人营养管理应用。无需登录，日常不使用外网、云数据库或云端AI。

1. 双击 **启动.cmd**，浏览器打开后完成六步个人档案。
2. 之后在首页查看实际记录和计划；只有确认吃过的食物才计入摄入。
3. 使用完可关闭浏览器；要停止本机服务，双击 **停止.cmd**。

正式个人资料保存在 `%LOCALAPPDATA%\MyNutritionAssistant` 的独立加密文件中，刷新或清除浏览器数据不会删除它们。请在“个人档案”中创建带密码的便携备份，另存到其他磁盘。

使用方法、备份恢复、模型等待与故障处理见 [使用说明](docs/user-guide.md)。安装维护见 [安装说明](docs/installation.md)，开发与测试进度见 [实施进度](docs/progress.md)，逐项验收见 [验收记录](docs/acceptance-results.md)。

完整测试入口为 **测试.cmd**。测试使用独立目录和合成档案，包含真实本地模型与Edge操作。

真实整机重启、另一Windows账户恢复、物理断网三项尚待人工验收，其余检查以验收记录与最终测试证据为准。
