# 膳算安卓局域网安装版

用户已选择“怎样快怎样来”，采用此前提出的同一 Wi-Fi、电脑持续开机的安卓 APK 路线，不等待公网发布。现有 Windows 桌面服务及数据保持原位。

## 交付

通用、可自行安装的签名 APK；电脑端一键启动/停止手机连接；连接配置文件；中文使用说明。手机复用现有 React 界面和真实电脑 AI，不建立第二份健康数据库。

## 边界

新增独立 HTTPS 转发进程，绑定用户选定的 RFC1918 局域网 IPv4 地址，默认端口18766。原服务仍仅监听127.0.0.1:18765。转发进程只访问固定本机地址，所有接口及静态资源均需256位随机凭据，拒绝其他Host/Origin、明文协议和外部客户端。写请求校验独立CSRF；不透传浏览器到本机服务的Cookie或任意请求头。限制上传大小与并发。健康数据不记入日志。手机不开放整体恢复、删除、明文导出或停止电脑服务。

证书与凭据使用Windows DPAPI保护；启动时为当前IP生成自签名证书。连接文件包含地址、证书SHA256指纹、访问凭据，不含健康资料，需由用户私下传到手机。安卓只允许该局域网HTTPS地址，严格核对证书指纹及有效期，绝不无条件忽略证书错误。凭据用AndroidKeyStore加密保存，禁止云备份；清除连接后删除凭据和WebView缓存。相机采用系统拍照/图片选择器。

电脑启动先确认原服务及原数据目录，不创建替代健康库。网络地址改变时重新生成连接文件并导入手机。关闭转发进程立即停止手机访问，原桌面服务继续可用。默认不修改系统防火墙；如防火墙阻挡，说明精确放行路径，不关闭防火墙。

## 验证

真实隔离加密数据库验证授权、CSRF、照片传输、记餐/饮水、数据版本、限制接口、来源校验与本机回归。TLS连接验证证书固定，构建并校验APK签名与权限。浏览器以手机尺寸检查页面及主题。没有连接实体安卓设备时明确标记实机安装、相机和Wi-Fi连通性待用户验收。
