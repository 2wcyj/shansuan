# 膳算云端隐私说明草案

> 草案版本：`2026-10-21-v1`。这是供产品与法律审阅的开发草案，不是正式上线隐私政策。正式试用前必须补齐责任主体、联系渠道、保存期限、服务商信息和个人信息保护影响评估，并经负责人及法律顾问确认。

## 处理目的与信息类别

在用户明确、单独同意后，膳算云端拟处理个人健康档案、疾病与过敏信息、饮食和生活记录、用户主动上传的食物照片及饮食问答，用于保存用户资料、生成饮食建议、分析用户确认的食物记录及生成阶段报告。疾病、健康和过敏信息属于敏感个人信息。

注册、登录、密码安全与邀请码核验所需的账户信息独立于健康信息同意。拒绝健康信息处理同意不应阻止用户登录或提出账户删除请求，也不会因此创建健康档案。

## 存储、访问和第三方

目标架构将云端业务数据存放在中国大陆的云服务区域，并采用账户隔离、数据库行级安全和应用层加密。具体服务商、区域、密钥托管方式、运维访问人员及跨境情况尚未确定，正式上线前必须据实补充。本版本没有接入广告 SDK、营销画像、在线支付或第三方 AI 服务；后续任何处理方或目的变更都必须先更新告知并取得必要授权。

## 保存期限与用户权利

账户、健康数据、照片、AI 中间内容、日志及备份的具体保存期限尚未确定。上线前必须明确各类数据的期限、自动清理策略、备份删除周期，以及用户查阅、复制、更正、撤回同意和删除申请的受理渠道与完成期限。

撤回健康信息处理同意后，应停止新的健康信息处理。撤回不影响撤回前基于同意进行的处理，也不应阻止用户行使数据权利。当前开发界面可在重新验证密码后下载包含当前数据、历史版本和授权记录的未加密 JSON 副本，也可通过明确确认语申请立即删除主数据库账户及级联数据。账户含附件时暂拒绝不完整导出或删除；最后一个管理员需先移交权限。完整附件清理、备份保留与到期清理仍待实现和正式公示，不能将本服务用于真实健康资料。

## 当前状态

当前项目尚未部署公网。云端已有基础账户 JSON 导出和数据库账户删除流程，但照片/对象存储、含附件的完整导出删除协调、生产密钥管理、备份恢复及完整云端健康资料界面尚未完成。当前开发环境不得输入真实健康资料。正式开放前必须完成法律审阅、明确数据与备份保存期限、安全评估和权利请求演练。
