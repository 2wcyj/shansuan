# 膳算手机网页内测开发计划

日期：2026-10-19。状态：开发计划，尚未执行联网改造或部署。

## 1. 已确认的交付范围

- 只面向中国大陆；本人和10位朋友，按11个独立账号准备。
- 首轮通过手机浏览器访问一个HTTPS链接，适配安卓Chrome等主流浏览器、iPhone Safari；微信内置浏览器单独验证，遇到能力限制提供系统浏览器打开说明。
- 可用时提供添加到主屏幕的说明，不承诺所有浏览器显示相同的安装按钮。第一轮不制作安装包、不上架应用商店。
- 档案、计划、实际饮食、照片、问答、反馈和报告按账号自动保存；个人记忆可以查看、纠正与删除。
- 每月运行费用控制在100元以内。实际服务报价与使用额度需核实，不能将预算分配当作已经购买的资源或保证。
- 当前电脑本地版及其个人资料保持可用。正式资料不自动上传，也不开放当前电脑的本地服务给朋友访问。

产品细则沿用 [联网演进方案](online-evolution-plan.md)，本地业务行为以原有测试为回归依据。

## 2. 实施默认方案

复用现有React界面、FastAPI业务规则和深浅主题，新增独立的联网配置与PostgreSQL存储实现。单台小型大陆服务器运行网页、接口与数据库，照片/异地备份使用私有存储，实际资源规格通过核价和压测确定。云端AI由服务端调用，不在手机上暴露密钥。

建议邀请制注册、用户名和密码登录，提供一次性恢复码及撤销设备会话，避免首轮依赖短信服务。密码使用成熟密码哈希；恢复码只保存摘要，不能以公开邀请码或简单个人信息重置账号。登录方式属于实施建议，若已有合适身份服务可替换。

手机网页与API同源，使用安全会话Cookie和CSRF保护；服务端验证所有资源归属，不信任客户端提交的用户编号。邀请码限制兑换次数与有效期，所有者账号默认没有查看其他人健康内容的界面。

## 3. 按顺序执行的阶段

| 阶段 | 必须完成的工作 | 对应有效测试与通过条件 |
| --- | --- | --- |
| W0：开发与上线准备 | 盘点已有域名/服务器；列出月费、续费、流量、存储、AI和必要年费折算；独立配置与数据库准备；确认部署条件 | 原电脑版本全量回归；配置缺失明确报错；联网配置不能误连接正式本地库；报价与用量场景在预算内 |
| W1：邀请与账号隔离 | 邀请注册、登录退出、恢复码、登录限速、会话过期、用户归属及私有附件 | 两账号交叉读写/下载/任务查询被拒绝；邀请码不能重复/过期兑换；并发兑换不超名额；退出及重置后旧会话失效 |
| W2：现有功能联网化 | 档案、每日计划、实际记餐、生活记录、反馈、次日调整、七天报告、导出/删除；版本校验和操作唯一编号 | 过敏与营养规则保持；计划不冒充实际摄入；重复请求不重复记餐/叠加饮水；多设备冲突保留输入；数据库重开数据一致 |
| W3：自动保存与个人记忆 | 建档/编辑草稿、正在保存/已保存/失败状态；每人独立记忆与来源；纠正、失效和删除传播 | 网络失败不假成功；切换账号不串草稿；刷新/换设备读取已提交资料；推断不冒充医学事实；删记忆后旧摘要不能使其复活 |
| W4：云端AI与费用控制 | 真实图片分析、个人问答、结构化输出核验、超时取消、每人及总费用额度、任务排队 | 用实际服务测试图片与问题；篡改参数不能绕过限制；并发预占与重试不穿透预算；额度耗尽仍能手记和读取；失败不展示伪结果 |
| W5：手机体验与试用反馈 | 手机导航、表单键盘、拍照/相册、权限拒绝、主题、断网重试、前后台恢复、反馈入口 | 实际安卓与iPhone验证；浏览器自动化不能冒充真机验收；320/390/宽屏布局无溢出；截图清楚；弱网/权限失败保留输入；反馈默认不夹带健康正文 |
| W6：部署与邀请试用 | HTTPS、域名与实际适用手续、私有存储、备份恢复、监控、服务故障说明、用量面板、试用说明及回退版本 | 全量测试；从独立备份恢复并核对11账号归属；账号删除/恢复传播演练；旧数据升级失败可回退；服务与AI用量核对后再邀请 |

每阶段添加和运行相应测试，通过后单独Git提交。失败先定位修复，不删除测试、跳过测试或降低验收标准。云端模型验证必须调用实际选定服务；未配置凭据时记录为待验证，不将替身输出计入真实AI验收。全部阶段完成后运行所有适用测试，并单列真机和部署实测结果。

W0至W5的本地开发和隔离测试可在不购买服务、不上传当前个人资料的情况下推进；正式云端联调依赖资源与凭据。采购、部署及邀请前先准备可审阅的配置、费用与验收证据，再执行相应的外部操作。

## 4. 自动保存与数据更新的约定

健康档案草稿自动保存，确认后成为生效版本。照片识别和计划修改不直接计入实际摄入；用户确认吃过才记餐。网络失败时保留输入并提示重试，只有服务器确认才显示已保存。第一轮网页不承诺关闭浏览器后未提交的输入仍可恢复，也不把健康正文写入普通localStorage。

个人记忆按来源、时效和确认状态使用；每次推荐先读取本人的有效档案、相关实际记录和记忆。用户纠正优先于系统推断，健康限制优先于偏好。个人行为可以调整个人未来方案，不能自动修改所有用户共用的安全规则或模型版本。

网页更新先验证数据库向后兼容与旧页面行为，对过期页面要求刷新并保留可恢复的草稿，不缓存健康API正文或使用公共图片链接。服务端、规则与模型有明确版本和回退路径，更新不能覆盖历史实际记录。

## 5. 费用核算与使用入口

运行预算参考：基础服务50元、AI25元、照片/异地备份/额外流量10元、预留15元；均为预算分配，实际报价未核实。先按11人每天各3次照片分析与5次问答的场景核价，并单算摘要、重试和并发任务。超出预算先调整模型或用量，不省略账号隔离与备份。

正式入口必须使用独立部署的HTTPS域名，朋友无需让本人的电脑保持开机。链接和邀请码由本人决定何时、向谁发送；本计划不表示已经创建可访问链接、发送邀请或发生费用。
