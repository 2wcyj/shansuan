# 膳算桌面版

更新日期：2026-10-18。本轮为当前电脑增加可直接打开的桌面应用入口，并统一名称、窗口标题、界面名称与图标为“膳算”。

## 使用方式

桌面双击“膳算”图标即可打开。第一次进入会等待本地服务和模型准备，之后连接同一份本机资料。无需先打开项目中的启动窗口或自行输入地址。

入口使用本机现有Microsoft Edge的独立应用窗口，默认1040×900，可正常调整尺寸、最小化和关闭。界面与本机服务继续使用原项目技术栈，后台通过Python运行；没有地址栏和普通浏览器标签。无需额外下载Electron、WebView或云端组件。

桌面入口依赖当前 `食品` 项目目录、虚拟环境、已安装Edge和本机Python运行时。请保留它们在原位置。重新创建桌面图标可运行 `安装桌面应用.cmd`；要停止本机后台服务可运行 `停止.cmd`。本次没有设置开机自启动。

## 数据与启动校验

- 保留原有数据库、照片、备份格式及数据目录，不随改名迁移资料。
- 安装时识别当前服务正在使用的资料目录；未运行时检查已有资料。同一物理目录的Windows路径别名去重，不误认为两份资料。
- 桌面配置记住绝对资料位置，避免从资源管理器打开时因为环境路径不同而进入一份空库。
- 启动检查端口返回的应用标识、资料目录与目录摘要；已有匹配服务时复用服务，其他目录或其他程序占用时拒绝打开。
- 原有资料目录或已知数据入口丢失时明确报错，不用空白资料替代。
- 后台无控制台窗口；失败通过标题为“膳算 · 无法打开”的提示说明。启动日志在桌面配置目录的 `logs/startup.log`，只记录服务启动与错误，不记录健康正文。
- 桌面配置与独立Edge资料位于当前账户的 `%LOCALAPPDATA%\MyNutritionAssistantDesktop`。健康数据仍是应用个人档案中显示的独立加密文件，浏览器缓存不是数据来源。

## 名称与图标

更新HTML窗口标题、应用名称元信息、首页署名、更多菜单、其他页面抬头、问答身份及API说明名称。技术层内部标识与数据文件名保持兼容，以免影响旧资料与备份。

图标用一个餐碗和三份食物的简洁图形，提供SVG、192/512px PNG和16–256px多尺寸ICO。图标可由 `app/scripts/build_icon.py` 在本地重复生成；不依赖网络、字体下载或图片生成服务。Web App manifest提供应用名称、启动范围、深色背景与图标信息；桌面快捷方式为当前电脑的直接入口。
