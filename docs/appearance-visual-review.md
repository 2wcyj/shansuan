# 膳算：全页面外观与主题验收

本轮只调整外观。应用仍叫“膳算”，使用原有八个页面、推荐逻辑、本地模型、独立加密资料文件和备份恢复方式。附件中涉及新功能、商家合作、手机端、账户和云端的内容不在本轮实现范围。

## 统一的视觉系统

- 深色以 `#111321`、`#181B2B` 为背景，蓝紫、灰蓝、烟灰色作为内容表面；浅色以 `#EEF3FA`、`#F6F8FC` 为背景，使用蓝白、淡青和浅灰紫表面。
- `style.css` 集中管理两套背景、文字、玻璃、边线、阴影、交互色、图表色、圆角、间距和220ms过渡变量。辅助文字和交互色经过对比度调整，没有机械照搬参考色值。
- 统一侧栏、顶部工具栏、卡片、输入框、多选标签、按钮、状态提示、对话气泡、弹窗及图表。桌面继续保留侧栏；窄窗口导航可横向滚动，内容自然换行。
- 主标题与正文分级；首页右侧核心数字用300细体字重、数值与单位分开。表单、图表和长文本优先可读性，没有强行使用超大数字。
- 深色、浅色、跟随系统三个选项：首页在“更多 → 外观”，其他页面在顶部工具栏。窄窗口顶部用有名称与悬停提示的图标表示。
- 切换不刷新、不重新挂载页面，保留当前路由、滚动位置、表单、对话草稿和弹窗。跟随系统会响应系统变化；同一浏览器的其他窗口同步选择。
- 只有外观偏好存入浏览器 `shansuan.appearance`；默认跟随系统且未操作时不写入。健康数据仍在原有加密文件中，外观偏好不改变备份格式。清理站点数据后外观回到跟随系统，个人健康文件保留。

## 玻璃层级的具体实现

1. **背景**：大面积低对比蓝/紫径向渐变与纵向渐变，为半透明表面提供底色。
2. **内容**：普通卡片使用半透明表面、细边和轻高光，静止背景下以明度差区分；首页卡片另有多层宽幅渐变和静态模糊纹理。文字不参与模糊。
3. **浮动操作**：侧栏、顶部栏、首页悬浮输入栏使用背景模糊。滚动内容经过悬浮栏后方时，确实有内容被模糊；不依靠给空白背景增加模糊来制造层次。
4. **弹窗**：较实的玻璃面板和更清楚的边缘，下方遮罩降低背景亮度并轻微模糊，确保文字和输入优先可读。

这是CSS磨砂玻璃近似，没有实现苹果系统原生Liquid Glass的光学折射。减少动态效果时关闭动画与按压变换；减少透明度时使用更实表面并关闭背景模糊；无背景模糊支持时也有回退样式。

## 避免变成天气应用

只借用底色、材质、留白与数字排版，不引入城市、温度、天气图标、伪状态栏或灵动岛。首页显示实际摄入和营养估算；表单仍是分步填写，对话仍是消息流，照片仍是图片加结果，报告仍是图表加表格。缺数据继续显示未记录或未知，不编造健康评分。
