# 首页视觉实现与验收依据

本轮范围为首页。按要求先提供可运行首页、真实截图与回归测试，待视觉确认后再延伸到其他页面。视觉参考是用户上传的天气截图；页面内容仍来自本机个人营养数据。

## 视觉系统与组件

- 页面：`#111321` 到 `#171929` 的轻微纵向渐变，电脑端内容区域最大760px，保持单列。
- 五张卡片：蓝紫、灰蓝、靛蓝、烟灰蓝、灰紫五种低饱和表面。26px圆角、12px间隔，使用多层宽幅渐变、12px静态模糊、低透明度高光；不加载网络背景图。
- 排版：系统字体，主标题34–36px，卡片标题20–22px，核心数字300字重、最大56px。数值与单位分开，长数字主动缩小；文案自然换行，卡片允许增高。
- 操作：圆形更多按钮；原生模态菜单；悬浮胶囊问答/相机入口；轻量饮水按钮；统一线性图标、键盘焦点和按压反馈。
- 状态：真实空白使用破折号及解释，加载占位、读取失败重试、饮水失败提示、处理中禁用；保留原有手动保存的成功及错误反馈。
- 设计变量集中于 `app/frontend/src/home.css` 的 `.nutrition-home`，不全局覆盖其他页面。

## 玻璃材质的层级

1. 背景层：深蓝黑渐变，提供安静的整体基底。
2. 内容层：各卡片有自己的静态云雾纹理和局部亮度，文字层独立位于其上。内容卡片不依赖模糊空白背景来冒充玻璃。
3. 浮动控制层：底部栏采用半透明灰蓝表面、24px背景模糊、轻微饱和度、内侧高光和淡边。滚动卡片实际从栏后经过，是模糊的真实背景内容。
4. 模态层：更多菜单有独立半透明面板与背景模糊；页面遮罩降低亮度，强化当前操作区域。

这是CSS实现的磨砂玻璃近似，没有实现系统原生Liquid Glass的物理光学折射。不以“macOS质感”等文字判断代替真实页面检查。系统要求减少透明度时，控制栏与菜单改用实色表面；要求减少动态效果时关闭按压变换及过渡。缺少背景模糊能力时有实色回退。

## 内容与数据真实性

- 采用参考图的排版与材质，不使用天气、城市、温度、伪状态栏或灵动岛。
- 大数字表示已记录能量、蛋白质、推荐蛋白质和饮水，单位为kcal、g、ml；参考目标不等于医学处方。
- 首页摄入来自实际饮食记录，不把推荐计划当作已吃；餐数按实际记录的餐次去重。
- 近期状态读取近七个自然日各项最近填写的真实反馈。未填项显示未填写；没有感受数据时显示记录后生成，不编造分数或趋势。
- 现有数据只有饮水累计量，没有单次饮水时间，因此显示“今日累计 · 未记录单次时间”，不以其他生活字段的修改时间冒充喝水时间。
- 需要专业确认的目标保持待确认；健康限制阻止推荐时引导完善档案；待复查计划不会继续显示可用的推荐营养数值。
