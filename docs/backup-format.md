# 备份与恢复契约 v1

便携文件 `.mnab`：`MNAB`、32位大端格式版本1、16字节随机salt、AES-GCM容器。scrypt参数N=32768/r=8/p=1，派生256位密钥；密码长度10—1024字符。每次备份独立salt和nonce，认证上下文固定为版本标识。

认证容器内容包含应用格式版本、创建时间、数据库schema版本、同一事务快照的SQLCipher文件、恢复所需随机主密钥、加密图片及其校验值。主密钥仅在密码认证的密文内，不把原Windows DPAPI材料作为跨账户恢复的必要条件。不含模型，不含运行时。

本机自动备份 `.mnal` 使用另一个随机密钥AES-GCM认证加密，密钥由当前用户DPAPI保护。它适合本机回滚，不能冒充便携备份。每日首次启动检查及业务写入前保存上一次完整状态；备份失败阻止该次写入并提示，避免继续掩盖问题。保留最近14份日快照；迁移和恢复前快照单独保留，不自动清理。

恢复分为校验和提交：

1. 解开认证外壳，验证格式版本、schema、文件清单、体积和校验值。
2. 在新代目录写入仍然加密的数据库与图片；数据库完整性、业务实体、图片引用逐项验证。禁止容器文件名穿越目录。
3. 回传数据概况及短期有效票据；票据仅在当前进程中有效，绑定备份校验结果。不写出密码。
4. 用户明确输入整体恢复确认；锁定写入，先创建当前代的可验证本机快照，检查磁盘剩余空间，再保护新主密钥。
5. 使用临时指针文件和原子替换切换active代；切换前失败继续旧代，切换后新代必须已经完整。无需复制覆盖正在用的数据库。
6. 应用重启只读取完整active代；孤立的暂存代不能被当成已恢复结果，不能遇错自动重建空库。恢复成功使旧浏览器缓存和未完成任务失效。

全部删除明确包含活动代、旧代和恢复暂存，是否同时删除本机备份由用户选定；无法自动删除用户已下载或复制到其他位置的便携文件。读取导出是显式动作，CSV/JSON没有密码保护，界面需要说明。

故障测试覆盖错误密码、篡改、格式/schema不兼容、缺图、空间不足、快照失败、切换前中断和切换后重开。真实跨Windows账户验证单独记录，不能用临时文件夹测试替代。

第一版容器的JSON/base64解密后最大256MB，上传外壳最大512MB；校验阶段要求剩余空间至少原容器三倍加8MB。密码与明文容器只在内存，暂存/快照均为加密文件。暂存标记在重启时清理，已提交代保留。
