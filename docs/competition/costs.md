## 2 需重点核实的成本项

1. **KMS 调用**：启动 `check()` 与每次账户密钥包封都会计费；账户量与重启频率直接影响账单。
2. **RDS 主备**：高可用会接近双倍实例成本。
3. **OBS 流量**：若照片经公网下载而非内网，流量费上升。
4. **DCS**：最小规格也可能有固定月费。
5. **带宽**：公网访问按带宽计费，演示期可先用低带宽。

## 3 降本选项

- 联调期使用按需 ECS + 最低规格 RDS，演示前再扩。
- 照片接口在未接模型前可不启用 OBS，减少存储与流量。
- 不采购 GPU；模型走经核验的云 API 或本机推理。
