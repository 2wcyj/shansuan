# 膳算 v0.1.0 — 本地个人营养管理预览版

早期预发布版本（Pre-release），适合开发者和个人体验，不是稳定版或独立手机应用。

膳算将个人档案、饮食计划、实际记录和每日反馈连接起来，帮助个人管理日常营养。当前以 Windows 本地使用为主，无需登录，健康资料保存在本机加密文件中。

## 当前功能

- 个人档案、饮食目标、健康情况、过敏原与口味偏好。
- 个性化每日餐食推荐、替代方案与分量调整；计划与实际摄入分开记录。
- 本地模型食物图片分析和营养问答，营养结果标注为估算。
- 饮食、饮水、睡眠、运动、体重记录，以及每日反馈、次日方案调整和七天报告。
- 本地产品目录，区分自有产品、待核实资料和正式营养信息。
- 加密存储、手动恢复点、密码备份与恢复、数据导出和删除。
- 深浅主题和 Windows 桌面入口。

## 安装与使用

请按根目录 README.md 准备 Python、前端依赖及构建产物。基础功能可不加载模型运行；照片识别与模型问答需另行下载本地模型。源码压缩包不是开箱即用的安装包。

## 已知限制

- 仅面向早期个人体验，不提供公网多用户服务、云同步或独立 iOS 应用。
- 安卓端是局域网伴侣端，需要电脑持续运行；当前启动脚本缺少加密证书私钥的解锁参数，尚需修复与实机验收，不作为本版本可交付安装包发布。
- 目前测试脚本含原开发环境路径约定；照片识别不能确定隐藏配料、过敏原或精确重量。
- 整机重启、跨 Windows 账户恢复、物理断网和安卓实机体验仍待人工验收。
- 应用不替代医生或营养师，不提供医学诊断和治疗建议。
